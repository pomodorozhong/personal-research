# Topic root READMEs

Treat a topic root README as an entry point when it introduces a collection of documents. A README that contains a complete lesson should use the guide or walkthrough guidance linked from SKILL.md instead.

- Open with a short, plain explanation of the topic and what the collection covers.
- Link to the available guides using meaningful titles. Under each link, list the concrete questions it answers or the tasks it helps with. Group those questions beneath the guide they belong to, using a nested list when that is easiest to scan.
- When adding a guide, add or update its specific index entry. A generic link to browse a directory does not tell readers which document serves their question.
- Arrange links in a useful reading order, or group them by reader need. State prerequisites or a suggested starting point only when they help someone choose.
- Keep detailed explanations in the linked documents. Include enough context here to distinguish them, without duplicating their contents or promising coverage they do not contain.
- Add a source, specification, or freshness note only when it helps interpret the collection.

For example, an index entry for a retry guide might ask "Which failures should be retried?" and "How do delay and retry limits affect recovery?" Those questions describe the guide's actual coverage more clearly than "Comprehensive retry guide."

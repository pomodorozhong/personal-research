These descriptions cover the observed paths, not all catalogue features. They do not establish runtime speed, memory use, language quality, or successful capture on the target Mac.

## What these patterns tell us

**Our analysis:** the projects separate speech recognition, speaker handling, and generation of notes well enough to make them useful units for the first experiments. Their scheduling differs: some processing runs during the call, some after it, and some only when requested. We should test those schedules explicitly rather than assuming every model must remain active together.

Source details also show why a feature cannot be inferred from a model name alone. HushScribe's speaker labels are finalized after the session, so final labelled turns do not imply live attribution. VOA's structured action output does not provide separate owner/deadline fields, and its prompt requests English output for non-English input; meeting language and desired note language therefore need explicit tests. These are implementation choices to evaluate against the catalogue. [HushScribe architecture](https://github.com/drcursor/HushScribe/blob/51103f0c8f97344ec7ecdf6480a2ee53cd9a0e92/ARCHITECTURE.md), [VOA extraction source](https://github.com/justanotherkevin/VOA/blob/d2a9a3af2cc76f8f0a674c017dd439bc8609ab49/src/main/pipeline/structured-summarizer.ts)

The full audit will trace intermediate artifacts, record exact model/runtime/configuration choices, map every `MN-01`–`MN-22` dependency, and identify missing application work. The [investigation plan](investigation-plan.md#three-phase-roadmap) defines that completion condition. No local feasibility conclusion is made here.

## Method and limits

Read the pinned READMEs, architecture/pipeline documents, and selected source sections listed above. Cross-checking was limited to the main paths and the specific examples discussed here; the full implementation, dependency licenses, model configurations, and every catalogue feature have not been audited. No applications or models were installed, no inference was run, and no target-Mac benchmark was performed.

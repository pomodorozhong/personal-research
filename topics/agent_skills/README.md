# Agent Skills

Skills package reusable instructions and supporting files for agent workflows. This guide explains the format, how agents discover skills, where teams store and distribute them, and how to organize one concrete document-generation workflow.

## Find the right guide

- **What belongs in a skill, and how does Codex discover and use it reliably?** Start with [Basics](basics.md) for the portable format, progressive disclosure, Codex-specific behavior, authoring, security, and iteration.
- **Where should I store skills, and how can I share them across projects and agents?** See [Storage and distribution](storage-and-distribution.md) for project and personal folders, Git repositories, installers, registries, and managed catalogs.
- **How should I structure a document-generation workflow, and where does its template belong?** See the [Document generation example](document-generation-example.md) for workflow and formatting responsibilities, templates, scripts, and validation.

The [Agent Skills specification](https://agentskills.io/specification) defines the portable package format. Paths, invocation, installation, and sharing vary by product. Product details in these guides were checked on 2026-09-29; recheck the linked documentation before relying on them.
